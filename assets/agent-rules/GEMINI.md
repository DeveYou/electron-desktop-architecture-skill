# Gemini / Antigravity project guidance

Use the portable `electron-desktop-architecture` skill whenever implementing an Electron + React desktop app. The skill's `SKILL.md` is the canonical workflow and its references contain architecture/security/design-system guidance.

Prefer a module-driven modular monolith, framework-independent domain/application behavior, capability-only preload, schema-validated authorized main IPC, semantic tokens and accessible UI. Execute applicable tests/builds and state results honestly. Respect any existing repository conventions and policy files.
